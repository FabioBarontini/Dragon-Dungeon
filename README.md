# Dragon Dungeon — First Quest

Versione pronta per Vercel, senza backend e senza dipendenze.

## Pubblicazione
1. Carica la cartella su GitHub.
2. Su Vercel scegli **New Project** e importa il repository.
3. Framework: **Other** / nessun framework.
4. Build Command: lascia vuoto.
5. Output Directory: lascia vuoto.
6. Deploy.

Oppure trascina la cartella in Vercel se usi il metodo di importazione disponibile nel tuo account.

## Contenuti
- intro fantasy
- mappa del dungeon
- 4 stanze
- gemme e sblocco progressivo
- indizi
- effetti sonori generati dal browser
- animazioni e atmosfera fantasy
- schermata finale
- campo per il nome della squadra

Nota: per rispettare le policy del browser, il primo suono parte dopo una prima interazione dell'utente.
