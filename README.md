# Dragon Dungeon — RPG V1
Sito statico HTML/CSS/JS pronto per Vercel.

## Pubblicazione
Importa questa cartella/repository in Vercel. Non serve framework, build command o backend.

## Controlli
WASD / frecce = movimento
E = interazione
M = mappa

## Struttura
Esplorazione top-down, NPC, nemici, porte, inventario, gemme, enigmi, mappa, dialoghi, effetti sonori e boss finale.
